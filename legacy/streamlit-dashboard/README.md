# Legacy: Streamlit Dashboard

Esta pasta preserva a versão original do sistema, desenvolvida em **Streamlit + Python puro**, antes da migração para a stack atual **React + FastAPI**.

## Contexto

- **Origem:** primeira versão operacional do sistema de gestão da locadora
- **Período:** utilizada antes da refatoração para arquitetura React + FastAPI
- **Status:** substituída pela interface web atual (`frontend/`)
- **Motivo da preservação:** referência histórica e contexto arquitetural

## Stack original

- Python 3.x
- Streamlit
- Pandas
- OpenPyXL

## Como executar (apenas referência)

```bash
pip install streamlit pandas openpyxl
streamlit run app.py
```

## Nota

Este arquivo **não é mantido**. Pode estar desatualizado em relação ao modelo de dados atual.
A interface oficial é o frontend React em `frontend/`.
